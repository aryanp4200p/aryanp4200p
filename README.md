A personal finance application that helps users track expenses, manage transactions, and gain financial insights using AI.

**Key Features**
- Expense and income tracking.
- Receipt scanning using OCR.
- Interactive financial dashboards and visualizations.
- AI-powered financial insights and assistance.
- Responsive interface with light and dark themes.

**Tech Stack:** React, Tailwind CSS, FastAPI, Python, AI/ML.
